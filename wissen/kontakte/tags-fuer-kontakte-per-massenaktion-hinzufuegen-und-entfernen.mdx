Diese Funktionen bieten eine verbesserte Kontrolle über Massenaktionen für Tags und ermöglichen eine effizientere Kontaktverwaltung. Du kannst ausgewählte Tags hinzufügen, ausgewählte oder alle Tags von ausgewählten Kontakten entfernen und sie bei Bedarf wiederherstellen.

Diese Funktion ist derzeit über Labs verfügbar.

**IN DIESEM ARTIKEL**

- Funktion 1 – Tags per Massenaktion hinzufügen
- Funktion 2 – Tags per Massenaktion entfernen
- Funktion 3 – Entfernte Tags wiederherstellen

## Funktion 1 – Tags für ausgewählte Kontakte per Massenaktion hinzufügen

Du kannst mehrere Kontakte auswählen und Tags über eine Massenaktion hinzufügen.

**Anleitung:**

Schritt 1: Wähle Kontakte aus.

Schritt 2: Klicke auf die Massenaktion „Tag hinzufügen“.

Schritt 3: Benenne die Aktion und wähle aus, welche Tags diesen Kontakten hinzugefügt werden sollen. Klicke anschließend auf „Tags hinzufügen“.

Schritt 4: Überprüfe den Fortschritt anhand der Prozentanzeige.

## Funktion 2 – Tags von ausgewählten Kontakten per Massenaktion entfernen

Du kannst mehrere Kontakte auswählen und Tags über eine Massenaktion entfernen.

**Anleitung:**

Schritt 1: Wähle Kontakte aus.

Schritt 2: Klicke auf die Massenaktion „Tag entfernen“.

Schritt 3: Benenne die Aktion und wähle aus, welche Tags von diesen Kontakten entfernt werden sollen, oder wähle die Option zum Entfernen aller Tags.

Schritt 4: Klicke auf „Tags entfernen“.

Schritt 5: Überprüfe den Fortschritt anhand der Prozentanzeige.

## Funktion 3 – Entfernte Tags wiederherstellen

Du kannst entfernte Tags wiederherstellen.

**Anleitung:**

Schritt 1: Gehe zur Seite „Massenaktionen“ und klicke rechts auf das Drei-Punkte-Menü.

Schritt 2: Klicke auf „Wiederherstellen“, um den Wiederherstellungsprozess zu starten.

Schritt 3: Der Vorgang wird als neue Aktion in der Übersicht der Massenaktionen angezeigt.
