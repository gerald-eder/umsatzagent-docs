## Seitenaufrufe

Wie oft deine Funnel-Seiten aufgerufen werden.

|  |  |
| --- | --- |
| **Typ** | **Beschreibung** |
| Alle | Alle Seitenaufrufe – einschließlich wiederholter Besuche. |
| Eindeutig | Eindeutige Besucher, die die Seite aufgerufen haben. |

> **Beispiel: 1 Person besucht die Seite zweimal → Alle = 2, Eindeutig = 1.**

---

## Opt-ins

Erfasst Nutzer, die Interesse an deinem Angebot zeigen.

|  |  |
| --- | --- |
| **Typ** | **Beschreibung** |
| Alle | Anzahl der Nutzer, die sich für das Produkt angemeldet haben, das Produkt gekauft haben, ein Formular oder eine Umfrage abgeschickt haben oder einen Termin über einen Kalender gebucht haben. |
| Rate | „Alle Opt-ins“ geteilt durch eindeutige Seitenaufrufe. |

> **Beispiel: 50 Opt-ins bei 200 eindeutigen Aufrufen → Rate = 25 %**

---

## Verkäufe – Bestellungen

Zählt die Käufe in deinem Funnel.

|  |  |
| --- | --- |
| **Ebene** | **Beschreibung** |
| Funnel-Schritt-Ebene | Anzahl der getätigten Verkaufsbestellungen -> wie viele Bestellungen aufgegeben wurden (berücksichtigt nicht die Anzahl der gekauften Produkte oder Mengen). |
| Einzelne Produktebene | Wie oft das jeweilige Produkt gekauft wurde. |
| Bump-Produkt | Wie oft das Bump-Produkt gekauft wurde. |

> **Beispiel: 30 Bestellungen in einem Schritt aufgegeben, 18 davon enthielten Produkt A und 5 enthielten das Bump-Produkt. Somit Funnel-Schritt-Ebene = 30, Einzelne Produktebene = 18 und Bump-Produkt = 5.**

---

## Verkäufe – Rate

Zeigt die Conversion von Aufrufen zu Käufen.

|  |  |
| --- | --- |
| **Ebene** | **Beschreibung** |
| Funnel-Schritt-Ebene | Anzahl der Käufe eines beliebigen Produkts geteilt durch eindeutige Seitenaufrufe. |
| Einzelne Produktebene | Anzahl der Käufe des jeweiligen Produkts geteilt durch eindeutige Seitenaufrufe. |
| Bump-Produkt | Anzahl der Käufe des Bump-Produkts geteilt durch die Gesamtzahl der für den Schritt aufgegebenen Bestellungen. |

> **Beispiel: 20 Bump-Käufe bei 100 Bestellungen → Rate = 20 %.**

---

## Verkäufe – Menge

Gesamtzahl der verkauften Artikel.

|  |  |
| --- | --- |
| **Ebene** | **Beschreibung** |
| Funnel-Schritt-Ebene | Gesamtmenge aller in diesem Funnel-Schritt gekauften Produkte. |
| Produktebene | Gesamtmenge des spezifischen Produkts in diesem Funnel-Schritt. |

> **Beispiel: 10 Bestellungen mit jeweils 3 Artikeln → Menge = 30.**

---

## Verkäufe – Betrag

Gesamt erzielter Umsatz.

|  |  |
| --- | --- |
| **Ebene** | **Beschreibung** |
| Funnel-Schritt-Ebene | Gesamtwert aller in diesem Funnel-Schritt gekauften Produkte. |
| Produktebene | Gesamtverkaufswert eines spezifischen Produkts in diesem Funnel-Schritt. |

---

## Durchschnittlicher Warenkorbwert

Durchschnittlicher Umsatz pro Bestellung.

|  |  |
| --- | --- |
| **Ebene** | **Beschreibung** |
| Funnel-Schritt-Ebene | Gesamtbetrag geteilt durch Gesamtbestellungen. |
| Produktebene | Nicht zutreffend. |

> **Beispiel: 1000 $ Umsatz aus 20 Bestellungen → Durchschnittlicher Warenkorbwert = 50 $.**

---

## Einnahmen/Seitenaufrufe

Umsatz pro Seitenaufruf.

|  |  |
| --- | --- |
| **Typ** | **Beschreibung** |
| Alle | Verkaufswert geteilt durch alle Seitenaufrufe (nicht eindeutige Seitenaufrufe). Gesamtverkaufswert ÷ Alle Seitenaufrufe. |
| Eindeutig | Einnahmen geteilt durch eindeutige Seitenaufrufe. Gesamtverkaufswert ÷ Eindeutige Seitenaufrufe. |

> **Beispiel: 5000 $ Umsatz bei 5000 Seitenaufrufen → 1 $ pro Aufruf.**

---

## Leistungsindikatoren

**Zielvorgaben**

1. Wachsende eindeutige Besucher und Opt-ins.
2. Gesunde und stabile Conversion-Raten.
3. Hoher durchschnittlicher Warenkorbwert und hoher Umsatz pro Aufruf.

**Warnsignale bei der Leistung**

1. Sinkender oder dauerhaft niedriger eindeutiger Traffic.
2. Niedrige Opt-in- oder Verkaufs-Conversion-Raten.
3. Geringe durchschnittliche Bestellwerte oder schwache Upsell-Performance.
