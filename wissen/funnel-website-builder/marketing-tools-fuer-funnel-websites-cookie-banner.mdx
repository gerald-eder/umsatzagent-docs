### Wichtiger Hinweis

Die `<noscript>`-Tags **müssen entfernt werden**, da das Cookie-Banner von UmsatzAgent eine JavaScript-basierte Lösung ist. `<noscript>` ist für Browser gedacht, die kein JavaScript unterstützen. Das Einbinden kann dazu führen, dass Cookies unbeabsichtigt ohne Einwilligung der Nutzer gesetzt werden.

### Marketing-Tools mit Cookie-Einwilligung integrieren

Bei der Integration von Marketing-Tools mit dem Cookie-Einwilligungsbanner kannst du prüfen, welchen Cookie-Kategorien die Nutzer zugestimmt haben. Folge der Anleitung für gängige Marketing-Tools.

#### Hinweis zur Implementierung:

Der folgende Code sollte deine bestehenden Tracking-Codes für **Meta-Pixel, Google Tag Manager (GTM) oder Google Analytics (GA)** ersetzen. Füge ihn in den Einstellungen für Funnels, Websites oder Webinare in den **Header-Code der Seite** oder den **Head-Tracking-Code** ein. Diese Vorlage gewährleistet die ordnungsgemäße Integration mit dem Cookie-Einwilligungsbanner.

### Cookie-Kategorien auslesen: Der folgende Code ist optional, wenn du die Einwilligung oder akzeptierte Kategorien für anderen benutzerdefinierten Code oder JavaScript von Drittanbietern auslesen möchtest

```
// Helper function to get consented categories
function getConsentedCategories() {
  const categoriesCookie = document.cookie
    .split('; ')
    .find(row => row.startsWith('cookie-categories='));

  if (categoriesCookie) {
    // Convert cookie value to array
    return categoriesCookie.split('=')[1].split(',');
  }
  return [];
}

// Helper function to check if category is allowed
function isCategoryAllowed(category) {
  const categories = getConsentedCategories();
  return categories.includes(category);
}

// Helper function to get cookie config
function getCookieConfig() {
  const cookieConfig = document.cookie
    .split('; ')
    .find(row => row.startsWith('cookie-config='));

  if (cookieConfig) {
    return cookieConfig.split('=')[1]; // Returns: all, essential, or custom
  }
  return undefined; // Return undefined if user hasn't made a choice yet
}
```

###

### Wichtige Hinweise:

1. Die Cookie-Kategorien werden im Cookie cookie-categories gespeichert
2. Kategorien sind durch Kommas getrennt (z. B. "essential,advertising,analytics")
3. Prüfe beim Laden deiner Marketing-Tools immer die anfängliche Einwilligung
4. Reagiere auf Events zur Einwilligungsänderung, um die Tool-Einstellungen zu aktualisieren
5. Entferne alle `&lt;noscript>`-Tags, da sie die Einwilligungsprüfung umgehen können
