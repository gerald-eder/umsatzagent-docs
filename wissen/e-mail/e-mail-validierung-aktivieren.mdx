Die E-Mail-Validierung ist ein Prozess, der prüft, ob eine E-Mail-Adresse zustellbar ist. Dieses Tool stellt fest, ob E-Mails an diese E-Mail-Adresse zugestellt werden können, bevor du eine E-Mail sendest.

**Bitte beachten:**

```
Die E-Mail-Validierungsfunktion ist für das integrierte E-Mail-System von UmsatzAgent verfügbar.
```

## So funktioniert die E-Mail-Validierung

- Alle E-Mail-Adressen werden vor dem Senden validiert, sofern sie noch nicht validiert wurden. Vor dem E-Mail-Versand wird das Validierungsdatum geprüft. Liegt die Validierung länger als 90 Tage zurück, erfolgt eine erneute Prüfung.
- In den Kontaktdetails kannst du die Prüfung manuell durchführen:
  - Öffne den Kontakt > scrolle auf der rechten Seite nach unten > klicke auf das Briefumschlag-Symbol.
  - |  |  |
    | --- | --- |
    |  | - Rot = Ungültig oder zuvor unzustellbar (Bounce). Der Fehler gibt an, warum die E-Mail ungültig ist. |
    |  | - Grün = Verifiziert |
    |  | - Gelb = Verifiziert |

## FAQ

### Was prüft die E-Mail-Validierung?

- Die Syntax der E-Mail-Adresse ist korrekt.
- Die Domain ist für den Empfang von E-Mails eingerichtet.
- Die E-Mail-Adresse existiert.
- Die E-Mail-Adresse ist keine Hochrisiko-Adresse.
- Die E-Mail-Adresse ist nicht rollenbasiert, wie info@domain.de oder admin@domain.de.

### Warum ist die E-Mail-Validierung wichtig?

Die E-Mail-Validierung bietet folgende Vorteile:

- Steigert deine Zustellrate durch das Entfernen ungültiger E-Mail-Adressen.
- Hält deine Kontaktliste sauber und aktuell.
- Verbessert deine E-Mail-Marketing-Kennzahlen wie Klickrate (CTR), Öffnungsrate und Click-to-Open-Rate (CTOR).
- Schützt deine Absender-Reputation.

### Wie wirkt sich die E-Mail-Validierung auf meine E-Mail-Zustellbarkeit aus?

Die E-Mail-Zustellbarkeit wird durch unzustellbare E-Mails (Bounces) stark beeinträchtigt. Reduziere Bounces, indem du die Validierung im Vorfeld durchführst.

Die Reputation deiner IP-Adresse und Domain leidet, wenn dein E-Mail-Dienstanbieter deine E-Mail nicht im Posteingang eines Empfängers zustellen kann. Dies beeinträchtigt zukünftige Zustellungen, da E-Mail-Dienste anhand der IP- und Absender-Reputation entscheiden, ob Nachrichten zugestellt werden. Bei einer schlechten Absender- oder IP-Reputation stufen E-Mail-Dienste deine E-Mails möglicherweise als Spam ein oder stellen sie gar nicht zu.

### Wann sollte ich meine E-Mail-Liste validieren?

Wenn du eine Liste gekauft hast (wovon dringend abgeraten wird) oder eine Liste übernommen hast, die du nicht kennst, empfiehlt sich die E-Mail-Validierung.

Auch wenn deine Liste gewachsen ist oder die letzte Überprüfung deiner E-Mail-Adressen länger zurückliegt, solltest du deine Kontaktliste validieren.
