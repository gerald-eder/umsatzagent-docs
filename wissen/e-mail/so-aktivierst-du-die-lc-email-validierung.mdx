Die E-Mail-Validierung ist ein Prozess, der prüft, ob eine E-Mail-Adresse zustellbar ist. Dieses Tool ermittelt vor dem Versenden einer E-Mail, ob Nachrichten an diese E-Mail-Adresse zugestellt werden können.

**Bitte beachten:**

```
Die E-Mail-Validierung steht nur für LC Email- und Mailgun-Nutzer zur Verfügung.
```

## So funktioniert die E-Mail-Validierung

- Alle E-Mail-Adressen werden vor dem Senden validiert, falls dies noch nicht geschehen ist. Vor dem E-Mail-Versand wird das Validierungsdatum geprüft. Liegt die Validierung mehr als 90 Tage zurück, erfolgt eine erneute Validierung.
- In den Kontaktdetails kannst du die Prüfung manuell durchführen:
  - Öffne den Kontaktdatensatz > scrolle auf der rechten Seite nach unten > klicke auf das Briefumschlag-Symbol.
  - |  |  |
    | --- | --- |
    |  | - Rot = Ungültig oder zuvor gebounct. Die Fehlermeldung gibt an, warum die E-Mail-Adresse ungültig ist. |
    |  | - Grün = Verifiziert |
    |  | - Gelb = Verifiziert |

## FAQ

### Was prüft die E-Mail-Validierung?

- Die Syntax der E-Mail-Adresse ist korrekt.
- Die Domain ist für den Empfang von E-Mails eingerichtet.
- Die E-Mail-Adresse existiert.
- Die E-Mail-Adresse ist keine Hochrisiko-Adresse.
- Die E-Mail-Adresse ist nicht rollenbasiert, wie etwa info@domain.com oder admin@domain.com.

### Warum ist die E-Mail-Validierung wichtig?

Die E-Mail-Validierung ist aus folgenden Gründen wichtig:

- Steigert deine Zustellrate durch das Entfernen ungültiger E-Mail-Adressen.
- Erhält die Listenhygiene, indem deine E-Mail-Liste aktuell gehalten wird.
- Verbessert deine E-Mail-Marketing-Kennzahlen wie Klickrate (CTR), Öffnungsrate und Click-to-Open-Rate (CTOR).
- Schützt deine Absender-Reputation.

### Wie beeinflusst die E-Mail-Validierung meine E-Mail-Zustellbarkeit?

Die E-Mail-Zustellbarkeit wird stark durch Bounces beeinträchtigt. Senke die Bounce-Rate, indem du E-Mail-Adressen vorab validierst.

Deine IP- und Domain-Reputation leidet, wenn dein E-Mail-Dienstanbieter (ESP) deine E-Mail nicht im Posteingang eines Empfängers zustellen kann. Das wirkt sich auf die zukünftige Zustellbarkeit aus, da E-Mail-Clients anhand der IP- und Absender-Reputation entscheiden, ob deine Nachrichten zugestellt werden. Bei einer schlechten Absender- oder IP-Reputation stufen E-Mail-Clients Nachrichten deiner Domain möglicherweise als Spam ein oder stellen sie gar nicht zu.

### Wann sollte ich meine E-Mail-Liste validieren?

Wenn du eine E-Mail-Liste gekauft hast (wovon dringend abgeraten wird) oder eine Liste übernommen hast, die du nicht kennst, empfiehlt sich die E-Mail-Validierung.

Wenn deine Liste gewachsen ist oder die letzte Überprüfung schon länger zurückliegt, empfiehlt sich eine Überprüfung deiner E-Mail-Liste.
