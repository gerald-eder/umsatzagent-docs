Um unseren SMTP-Server zu nutzen, benötigst du die SMTP-Zugangsdaten deiner Domain.

Beachte, dass die SMTP-Zugangsdaten für jede hinzugefügte Domain eindeutig sind. Um die Liste der hinzugefügten Benutzer einzusehen oder weitere Benutzer hinzuzufügen, öffne deine Domain-Einstellungen.

## So erstellst du SMTP-Zugangsdaten

```
SMTP-Zugangsdaten können direkt für deine dedizierte Domain erstellt werden.
```

1. Navigiere unter der dedizierten Domain zu **Einstellungen -> E-Mail-Dienste -> SMTP-Dienst -> Dedizierte Domain und IP -> SMTP-Einstellungen**.![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155023337421/original/nMyZojgr2ZYUAZSkyYnJ6GXwk_Eyr_1HGw.png?1711087651)
2. Klicke auf „Create New SMTP User“ und gib Benutzername sowie Passwort ein, um die Zugangsdaten zu erstellen.![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155023337477/original/3gfn3HeigPBnj1KhpAJrkIlpaoOzAJ0ONw.png?1711087786)![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155023337530/original/utUNsl_XodI8FsMRFgE8TrwwQdmfgvu_uA.png?1711087862)
   Beachte, dass pro dedizierter Domain maximal fünf SMTP-Zugangsdaten erstellt werden können.
3. ### SMTP-Einstellungen

```
SMTP-Serveradresse: smtp.umsatzagent.com
Sichere Verbindung: TLS/SSL je nach E-Mail-Programm/Website-SMTP-Plugin
SMTP-Benutzername: [DeinVergebenerName@DomainName.com]
SMTP-Passwort: [DeinVergebenesPasswort]
SMTP-Port: 25, 465 (SSL/TLS), 587 (STARTTLS) und 2525
```

---

## Welche Ports werden unterstützt?

Unsere Server unterstützen die Ports 25, 465 (SSL/TLS), 587 (STARTTLS) und 2525.

## Limits für SMTP und E-Mails

**SMTP-Limit:**

- Pro dedizierter Domain können maximal **fünf SMTP-Zugangsdaten** erstellt werden.

**Tägliches E-Mail-Limit:**

- Jedes Konto hat ein Limit von **1.500 E-Mails pro Tag**.
- Wenn das tägliche Limit überschritten wird, werden die **SMTP-Zugangsdaten automatisch aus allen dedizierten Domains gelöscht**.

---

## E-Mail-Preise

Alle eingehenden und ausgehenden E-Mails (An, CC und BCC) werden zum gleichen E-Mail-Versandpreis abgerechnet.
