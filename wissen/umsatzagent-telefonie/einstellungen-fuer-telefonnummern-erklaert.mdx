### Nummernname

Der interne Name für die Telefonnummer (z. B. „Haupt-Marketingnummer“ oder der Name einer Person, der diese Nummer zugewiesen ist).

### Weiterleitungsnummer

Die Telefonnummer, an die eingehende Anrufe auf diese Nummer weitergeleitet werden sollen (ruft jemand die Nummer an, wird der Anruf an die hier hinterlegte Nummer umgeleitet).

### Angerufene Nummer als Anrufer-ID übertragen

Standardmäßig wird bei deaktivierter Option die Telefonnummer des Anrufers als Anrufer-ID übertragen. Wenn du diese Option aktivierst, überträgt das System stattdessen die in UmsatzAgent hinterlegte Nummer als Anrufer-ID. So erkennst du sofort, dass der eingehende Anruf über das System eingeht.

### Anrufverbindung aktivieren

Ist diese Option deaktiviert, funktionieren eingehende Anrufe regulär: Die Verbindung wird sofort hergestellt, sobald du abhebst. Wenn du diese Option aktivierst, hörst du eine Flüsteransage, die dich auffordert, eine Taste auf deinem Telefon zu drücken, um den eingehenden Anruf anzunehmen.

**Warum diese Funktion nützlich ist:**

Im CRM kannst du Anrufstatus wie „verbunden“ oder „nicht verbunden“ als Auslöser für Automatisierungen nutzen – beispielsweise, um automatisch eine Rückruf-SMS bei verpasstem Anruf zu senden.

Damit das System solche Automatisierungen zuverlässig ausführen kann, muss es wissen, ob ein Anruf tatsächlich von einer Person angenommen wurde. Ohne diese Funktion wird eine Mailbox-Ansage oft fälschlicherweise als Gesprächspartner gewertet. Der Anruf gilt dann als verbunden, obwohl sich keine Person gemeldet hat.

Wenn die Option aktiviert ist, muss die annehmende Person eine Taste drücken, um das Gespräch zu verbinden. So erkennt das System zuverlässig, ob ein Mensch den Anruf entgegengenommen hat.

### Flüsteransage

Die Flüsteransage steuert die Nachricht, die der annehmenden Person vorgespielt wird, wenn die Anrufverbindungs-Funktion (Call Connect) aktiviert ist. Trage hier beispielsweise „UmsatzAgent-Anruf, drücke eine Taste“ ein. So weißt du direkt beim Abheben, dass der Anruf über das System eingeht und du eine Taste zur Annahme drücken musst.

### Anrufaufzeichnung

Wenn du die Anrufaufzeichnung aktivierst, werden Anrufe aufgezeichnet und direkt im Konversationsverlauf des jeweiligen Kontakts hinterlegt – zusammen mit E-Mails, SMS und Social-Media-Nachrichten. Beachte bei der Aktivierung die geltenden rechtlichen Bestimmungen und richte bei Bedarf eine entsprechende Ansage ein (z. B. „Dieser Anruf wird zu Qualitätszwecken aufgezeichnet“), um Anrufer darüber zu informieren.

### Anruf-Timeouts

#### Eingehendes Timeout: Die Zeitspanne (in Sekunden), die das System einen eingehenden Anruf klingeln lässt, bevor er beendet oder an eine Mailbox weitergeleitet wird (persönliche Mailbox oder im CRM hinterlegte Mailbox).

**Szenario 1:** Wenn der Kontakt deine persönliche Mobilfunk-Mailbox erreichen soll, lasse dieses Feld leer oder trage 60 Sekunden ein.

**Szenario 2:** Wenn das Telefon klingeln und der Kontakt die im CRM hinterlegte Mailbox erreichen soll, setze das eingehende Timeout auf ca. 20 Sekunden. Eine kurze Zeitspanne stellt sicher, dass es nicht lange genug klingelt, um deine persönliche Mailbox zu erreichen.

**Szenario 3:** Wenn eingehende Anrufe direkt auf die im CRM hinterlegte Mailbox geleitet werden sollen, setze das eingehende Timeout auf 1–4 Sekunden. Stelle sicher, dass zuvor eine Mailbox-Ansage (MP3- oder WAV-Datei) im Unternehmensprofil oder in den Profileinstellungen des zugewiesenen Benutzers hochgeladen wurde.

  

#### Ausgehendes Timeout: Die Zeitspanne (in Sekunden), die das System einen ausgehenden Anruf klingeln lässt, bevor der Anruf beendet wird. Ein kürzeres Timeout von ca. 30 Sekunden verringert die Wahrscheinlichkeit, die Mailbox des Kontakts zu erreichen. Das ist nützlich für Mailbox-Drop-Kampagnen oder wenn Mitarbeiter nur direkt erreichbare Kontakte annehmen möchten.

## FAQ

### Was ist das Standardverhalten, wenn das eingehende/ausgehende Timeout leer ist?

   Der Standardwert des Systems beträgt für beide Optionen 60 Sekunden.
