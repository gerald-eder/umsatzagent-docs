| Was sind WhatsApp-Anrufe? Sprache und Chat an einem Ort – kein Wechseln zwischen Apps erforderlich |

WhatsApp-Anrufe ermöglichen es dir, in Echtzeit mit deinen Kunden zu sprechen. Dies bietet eine persönlichere und direktere Verbindung im Vergleich zu reinen Textnachrichten. Es eignet sich besonders zur Klärung komplexer Fragen, zum schnelleren Abschluss von Geschäften oder für direkten Support.

Wenn WhatsApp-Anrufe direkt in deinem CRM verfügbar sind, musst du nicht mehr zwischen mehreren Apps oder Geräten wechseln. Alle Sprach- und Chat-Interaktionen werden an einem zentralen Ort verwaltet.

**Mit dieser Integration kannst du:**

|  |  |
| --- | --- |
| |  | | --- | | WhatsApp-Anrufe direkt aus dem CRM tätigen und annehmen | |
| |  | | --- | | Anrufverlauf zusammen mit Chat-Nachrichten für den vollständigen Konversationskontext einsehen | |
| |  | | --- | | Anrufberechtigungen und Aktivitäten über eine zentrale Plattform verwalten | |
| |  | | --- | | Antwortzeiten verkürzen und das Kundenerlebnis verbessern | |

| So aktivierst du WhatsApp-Anrufe Aktiviere Anrufe für dein Konto |

Um WhatsApp-Anrufe für dein Konto zu aktivieren, klicke auf den bereitgestellten Aktivierungslink und fülle das Anfrageformular mit den erforderlichen Daten aus. Nach dem Absenden wird der Zugriff auf WhatsApp-Anrufe **innerhalb von 24 Stunden für dein Konto freigeschaltet**.

```
Voraussetzungen — Stelle vor der Nutzung von WhatsApp-Anrufen Folgendes sicher:

✓ Die WhatsApp-Nummer muss von der Meta WhatsApp Business API unterstützt werden.
✓ WhatsApp-Anrufe werden NICHT für die Koexistenz unterstützt (WhatsApp-App + API auf derselben Nummer).
✓ Das Unternehmen muss ein Nachrichtenlimit von mindestens 2.000 vom Unternehmen initiierten Konversationen innerhalb eines rollierenden 24-Stunden-Zeitraums haben.
```

| Länderverfügbarkeit WhatsApp-Anrufe sind in den meisten Ländern verfügbar |

WhatsApp-Anrufe sind an den meisten Standorten verfügbar. Ausgehende WhatsApp-Anrufe werden derzeit jedoch in folgenden Ländern **nicht unterstützt**:

|  |  |  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

```
Befindet sich dein Unternehmen oder dein Kunde in einem dieser Länder, sind ausgehende WhatsApp-Anrufe derzeit nicht verfügbar.
```

| Eingehende WhatsApp-Anrufe (vom Kunden initiiert) Wenn dich ein Kunde direkt über WhatsApp anruft |

Eingehende Anrufe treten auf, wenn ein **Kunde dein Unternehmen über WhatsApp anruft**. Diese Anrufe erscheinen wie jede andere Benachrichtigung in deinem CRM. Du kannst den Anruf annehmen, ablehnen oder auf die Mailbox weiterleiten, falls konfiguriert.

**So funktioniert es im CRM:**

|  |  |
| --- | --- |
| |  | | --- | | Wenn ein Kunde anruft, siehst du einen Hinweis in deiner CRM-Nachrichten- oder Anrufoberfläche. | |
| |  | | --- | | ✅ Du kannst den **Anruf direkt im CRM annehmen** – kein separates Öffnen von WhatsApp erforderlich. | |
| |  | | --- | | Nach Beendigung des Anrufs werden Anrufdetails (Uhrzeit, Dauer, Ergebnis) gespeichert und zur späteren Einsicht mit der Konversation des Kunden verknüpft. | |

| WhatsApp-Anrufe einrichten Konfiguriere deine Telefonnummer und weise Benutzer für Anrufe zu |

Schritt 1 Öffne **WhatsApp** und gehe zu den **Einstellungen**.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069597360/original/bLs9rRGI73eKFGnEbBlIdQLz1ZGzhC7UyQ.png?1776768958)

Schritt 2 Wähle **Anrufe** aus dem Menü.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069597830/original/Uy52qjpXwlZx3meYlEa8ctfNLGNQt-yaDw.png?1776769266)

Schritt 3 Du siehst eine Liste der Telefonnummern, die derzeit als **verbunden** angezeigt werden. Wähle die Nummer aus, die du für Anrufe einrichten möchtest.

Schritt 4 Suche die gewünschte Nummer und klicke auf **Verwalten**.

Schritt 5 Vergib einen **Namen** (z. B. *Vertriebsteam*) zur einfachen Identifizierung.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069594284/original/3KQ8jnEyfOd6YZU7mPo-_NK5FjcfgRpcvQ.png?1776767351)

Schritt 6 Füge unter **WhatsApp-Anrufe weiterleiten an** die Benutzer hinzu, die eingehende Anrufe erhalten sollen. Lege einen **primären Benutzer** fest, bei dem es zuerst klingelt, und füge bei Bedarf weitere Benutzer als Vertretung hinzu.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069594793/original/dCUjG_mi_C1a9rPlaFcEylRgHT0yufXEGA.png?1776767564)

Schritt 7 Aktiviere **Sprachanrufe zulassen**, um WhatsApp-Anrufe für diese Nummer einzuschalten. Aktiviere **Rückrufbitte bei verpassten Anrufen erlauben**, damit Kunden einen Rückruf anfordern können, falls niemand abnimmt.

Schritt 8 Aktiviere **Anruf-Button anzeigen**, damit Kunden direkt auf deinem WhatsApp-Unternehmensprofil eine Anrufoption sehen.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069597841/original/psv8jkMyktJMlIftbzOGpEcKVr5qTDSpfQ.png?1776769284)

Schritt 9 Richte **Verfügbare Anrufer** und **Vorübergehend nicht verfügbare Anrufer** basierend auf den Arbeitszeiten und der Verfügbarkeit deines Teams ein.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069593579/original/gah6QaPHDW3Kxa4l3ND_VcpVDtFjW2r_vQ.png?1776767005)

```
Tipp: Halte die Anruferverfügbarkeit stets aktuell, um sicherzustellen, dass eingehende Anrufe immer an die richtige Person weitergeleitet werden und verpasste Anrufe minimiert werden.
```

| WhatsApp-Anrufberechtigungen einrichten Anrufberechtigungen von Kunden anfordern und verwalten |

```
Wichtig: WhatsApp erfordert die ausdrückliche Zustimmung des Kunden, bevor Anrufe für einen Kontakt aktiviert werden können. Vergewissere dich vor jedem Anruf, dass die Berechtigung aktiv ist.
```

Schritt 1 Gehe zu **Einstellungen** > **WhatsApp-Vorlagen**.

Schritt 2 Erstelle eine neue Vorlage, mit der du die Anrufberechtigung bei deinen Kunden anforderst.

Schritt 3 Wähle unter **Call-to-Action-Buttons** die Option **WhatsApp-Anrufberechtigungen**. Dadurch wird der Vorlage ein Button hinzugefügt, auf den Kunden tippen können, um dir die Anrufberechtigung zu erteilen.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069597849/original/76RQlsjsLAzwb5ORzWLmPRM0JMS8nO22Pw.png?1776769302)

Schritt 4 Wenn Kunden diese Nachricht erhalten, tippen sie auf den Button, um die Berechtigung für einen **befristeten** oder **unbefristeten** Zeitraum zu erteilen.

Schritt 5 Du kannst auch direkt einen Anruf-Button in Vorlagen einbinden und die Berechtigungsdauer je nach Anwendungsfall auf **1, 7, 15 oder 30 Tage** festlegen.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069593581/original/xbgjUIRB8nes2eipsg9DVpFbSttovJNkBw.png?1776767005)

Sobald die Kunden die Berechtigung erteilt haben, kannst du Anrufe durchführen.

Schritt 3 Sobald der Kunde die Berechtigung erteilt, aktualisiert sich sein Status auf **„Anrufberechtigungen unbefristet aktiv“** – oder zeigt die gewählte Dauer an.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155069597879/original/lKp8lQfL53xVS6OAK_pnVUFs8-v_SzL6wQ.png?1776769328)

| Häufig gestellte Fragen Häufige Fragen zu WhatsApp-Anrufen |

|  |
| --- |
| Kann ich WhatsApp-Anrufe über einen Desktop-Browser tätigen? Ja. In den Mitarbeitereinstellungen kannst du den **Standardkanal für WhatsApp-Anrufe** auf **Web App** setzen, wodurch Anrufe direkt über die CRM-Browseroberfläche abgewickelt werden können. |

|  |
| --- |
| Benötige ich vor einem Anruf die Erlaubnis des Kunden? Ja. WhatsApp erfordert die **ausdrückliche Zustimmung des Kunden**, bevor dein Unternehmen einen ausgehenden Anruf starten darf. Du musst eine Vorlage zur Anrufberechtigung senden und warten, bis der Kunde zustimmt. Eingehende Anrufe von Kunden erfordern keine vorherige Genehmigung. |

|  |
| --- |
| Wie lange ist eine Anrufberechtigung gültig? Eine Anrufberechtigung kann für einen **befristeten Zeitraum** (1, 7, 15 oder 30 Tage) oder **unbefristet** erteilt werden, je nach Auswahl des Kunden. Reagiert der Kunde nicht auf eine Anfrage, verfällt diese automatisch nach **7 Tagen**. |

|  |
| --- |
| Wie viele Berechtigungsanfragen kann ich an denselben Kunden senden? Du kannst **eine Anfrage alle 24 Stunden** und maximal **zwei Anfragen innerhalb von 7 Tagen** pro Kontakt senden. Diese Limits werden von WhatsApp automatisch durchgesetzt. |

|  |
| --- |
| Sind WhatsApp-Anrufe in meinem Land verfügbar? WhatsApp-Anrufe sind in den meisten Ländern verfügbar. Sie werden derzeit in den Vereinigten Staaten, Kanada, der Türkei, Ägypten, Vietnam und Nigeria **nicht unterstützt**. Befindet sich dein Unternehmen oder dein Kunde in einem dieser Länder, sind Anrufe derzeit nicht verfügbar. |

|  |
| --- |
| Was passiert, wenn ich einen eingehenden WhatsApp-Anruf verpasse? Wird ein Anruf nicht entgegengenommen, kann der Kunde einen Rückruf anfordern, sofern du in den Anrufeinstellungen die Option **Rückrufbitte bei verpassten Anrufen erlauben** aktiviert hast. Der verpasste Anruf wird außerdem zur Nachverfolgung in der Konversation des Kunden protokolliert. |

|  |
| --- |
| Können mehrere Teammitglieder denselben eingehenden Anruf erhalten? Ja. In der Einstellung **WhatsApp-Anrufe weiterleiten an** kannst du einen **primären Benutzer** zuweisen, bei dem es zuerst klingelt, und weitere Teammitglieder als Vertretung hinzufügen. Antwortet der primäre Benutzer nicht, wird der Anruf an den nächsten zugewiesenen Benutzer weitergeleitet. |

|  |
| --- |
| Kann ein Kunde die Anrufberechtigung widerrufen? Ja. Kunden können die Berechtigung jederzeit widerrufen, indem sie den WhatsApp-Chat mit deinem Unternehmen öffnen, auf den **Unternehmensnamen** tippen, zu **Berechtigungen für geschäftliche Anrufe** gehen und den Anrufzugriff deaktivieren. Nach dem Widerruf kann dein Unternehmen diesen Kontakt nicht mehr anrufen. |

|  |
| --- |
| Was ist ein Anrufergebnis und warum sollte ich es nutzen? Ein Anrufergebnis ist ein **Status-Tag**, das du nach einem Anruf vergibst – zum Beispiel *Gelöst*, *Nachfassen erforderlich* oder *Keine Antwort*. Die Erfassung von Anrufergebnissen sorgt für genaue Daten im Team, erleichtert die Nachverfolgung und verbessert die Berichterstattung im CRM. |

|  |
| --- |
| Wie viel Zeit habe ich nach Erhalt der Berechtigung, um anzurufen? Sobald ein Kunde die Anrufberechtigung erteilt hat, musst du den Anruf **innerhalb von 72 Stunden** tätigen. Erfolgt der Anruf nicht innerhalb dieses Zeitfensters, verfällt die Berechtigung und du musst sie erneut anfordern. |
